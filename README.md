## Red de Hopfield

Una **Red de Hopfield** es un tipo de red neuronal recurrente que funciona como memoria asociativa. Dada una entrada parcial o con ruido, la red converge hacia el patrón almacenado más cercano.

### Conceptos implementados

- Regla de aprendizaje de Hebb para almacenamiento de patrones
- Actualización asíncrona de neuronas
- Función de energía y convergencia
- Recuperación de patrones con ruido o datos incompletos
- Capacidad de almacenamiento y límites de la red
